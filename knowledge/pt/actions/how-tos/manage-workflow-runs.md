# Gerenciar fluxos de trabalho

_Você pode interagir manualmente com execuções de fluxos de trabalho para garantir que elas sejam executadas com eficiência._

## Links

* [Executar um fluxo de trabalho manualmente](manage-workflow-runs/manually-run-a-workflow.md)

  Quando um fluxo de trabalho é configurado para ser executado no workflow\_dispatch evento, você pode executar o fluxo de trabalho usando a guia GitHubGitHub CLIAções, ou a API REST.

* [Reexecutando fluxos de trabalho e tarefas](manage-workflow-runs/re-run-workflows-and-jobs.md)

  Você pode executar novamente um fluxo de trabalho, todos os trabalhos que falharam na execução de um fluxo de trabalho, ou trabalhos específicos em uma execução de fluxo de trabalho até 30 dias após sua execução inicial.

* [Cancelar a execução do fluxo de trabalho](manage-workflow-runs/cancel-a-workflow-run.md)

  Você pode cancelar uma execução de fluxo de trabalho que está em andamento, incluindo todas as tarefas e etapas.

* [Desabilitar e habilitar um fluxo de trabalho](manage-workflow-runs/disable-and-enable-workflows.md)

  Você pode desabilitar e habilitar novamente um fluxo de trabalho usando a interface do usuário de GitHub, a API REST, ou GitHub CLI.

* [Ignorar execuções de fluxo de trabalho](manage-workflow-runs/skip-workflow-runs.md)

  Você pode ignorar as execuções de fluxo de trabalho disparadas pelos eventos push e pull\_request incluindo um comando na mensagem de commit.

* [Excluir a execução de um fluxo de trabalho](manage-workflow-runs/delete-a-workflow-run.md)

  Você pode excluir uma execução do fluxo de trabalho que foi concluída ou que tem mais de duas semanas.

* [Baixar artefatos do fluxo de trabalho](manage-workflow-runs/download-workflow-artifacts.md)

  Você pode fazer o download de artefatos arquivados antes que expirem automaticamente.

* [Remover artefatos de fluxo de trabalho](manage-workflow-runs/remove-workflow-artifacts.md)

  Você pode recuperar o armazenamento usado GitHub Actions excluindo artefatos antes que eles expirem GitHub.

* [Gerenciando caches](manage-workflow-runs/manage-caches.md)

  Você pode monitorar, filtrar e excluir caches de dependência criados com base em seus fluxos de trabalho.

* [Aprovando execuções de fluxo de trabalho de forks](manage-workflow-runs/approve-runs-from-forks.md)

  Você pode aprovar manualmente as execuções de fluxo de trabalho disparadas pela solicitação de pull de um colaborador.
