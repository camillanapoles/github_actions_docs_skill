# Usar atestados de artefatos

_Use atestados de artefato para estabelecer a proveniência de build para o software que você produz e para verificar o software que você consome._

## Links

* [Usar atestados de artefatos para estabelecer a procedência de compilações](use-artifact-attestations/use-artifact-attestations.md)

  Os atestados de artefatos permitem que você aumente a segurança da cadeia de fornecedores de suas compilações, estabelecendo onde e como seu software foi criado.

* [Usando atestados de artefatos e fluxos de trabalho reutilizáveis para alcançar o SLSA v1 Build Level 3](use-artifact-attestations/increase-security-rating.md)

  A criação de software com fluxos de trabalho reutilizáveis e atestados de artefatos pode simplificar a segurança da sua cadeia de fornecedores e ajudar você a alcançar o SLSA v1.0 Build Level 3.

* [Impondo atestados de artefatos com um controlador de admissão do Kubernetes](use-artifact-attestations/enforce-artifact-attestations.md)

  Use um controlador de admissão para impor atestados de artefato em seu cluster Kubernetes.

* [Verificação de atestados offline](use-artifact-attestations/verify-attestations-offline.md)

  Os atestados de artefato podem ser verificados sem uma conexão de Internet.

* [Como gerenciar o ciclo de vida dos atestados de artefato](use-artifact-attestations/manage-attestations.md)

  Pesquise e exclua atestados de que você não precisa mais.
