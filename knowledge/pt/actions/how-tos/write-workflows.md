# Escrevendo fluxos de trabalho

_GitHub Actions os fluxos de trabalho podem automatizar tarefas em todo o ciclo de vida de desenvolvimento de software._

## Links

* [Usando modelos de fluxo de trabalho](write-workflows/use-workflow-templates.md)

  GitHub fornece modelos de fluxo de trabalho para uma variedade de linguagens e ferramentas.

* [Escolhendo quando seu fluxo de trabalho é executado](write-workflows/choose-when-workflows-run.md)

  Você pode configurar fluxos de trabalho para serem executados com base em um cronograma ou quando determinados eventos ocorrerem.

* [Escolhendo onde seu fluxo de trabalho é executado](write-workflows/choose-where-workflows-run.md)

  Você pode especificar o ambiente de computação em que seus trabalhos e fluxos de trabalho são executados.

* [Escolhendo o que seu fluxo de trabalho faz](write-workflows/choose-what-workflows-do.md)

  Fluxos de trabalho automatizam tarefas no seu ciclo de vida de desenvolvimento de software. Muitas tarefas que você conclui manualmente podem ser convertidas em um fluxo de trabalho do GitHub Actions.
