# Como gerenciar executores auto-hospedados

_Você pode hospedar seus próprios executores para executar fluxos de trabalho em um ambiente altamente personalizável._

## Links

* [Adicionar executores auto-hospedados](self-hosted-runners/add-runners.md)

  Você pode adicionar um runner autogerenciado a um repositório, a uma organização ou a uma empresa.

* [Como executar scripts antes ou depois de um trabalho](self-hosted-runners/run-scripts.md)

  Os scripts podem ser executado automaticamente em um executor autohospedado, diretamente antes ou depois de um trabalho.

* [Como personalizar os contêineres usados por trabalhos](self-hosted-runners/customize-containers.md)

  Você pode personalizar como o executor auto-hospedado invoca um contêiner para um trabalho.

* [Configurar o aplicativo do executor auto-hospedado como um serviço](self-hosted-runners/configure-the-application.md)

  Você pode configurar o aplicativo do executor auto-hospedado como um serviço para que inicie o aplicativo do executor automaticamente quando a máquina for iniciada.

* [Usar rótulos com os executores auto-hospedados](self-hosted-runners/apply-labels.md)

  Você pode usar etiquetas para organizar os seus executores auto-hospedados com base em suas características.

* [Usar os executores auto-hospedados em um fluxo de trabalho](self-hosted-runners/use-in-a-workflow.md)

  Para usar executores auto-hospedados em um fluxo de trabalho, você pode usar rótulos ou grupos para especificar o executor para uma tarefa.

* [Gerenciar o acesso a executores auto-hospedados usando grupos](self-hosted-runners/manage-access.md)

  Você pode usar políticas para limitar o acesso a runners auto-hospedados que foram adicionados a uma conta corporativa.

* [Monitorar e solucionar problemas de executores auto-hospedados](self-hosted-runners/monitor-and-troubleshoot.md)

  Você pode monitorar seus executores auto-hospedados para visualizar sua atividade e diagnosticar problemas comuns.

* [Remover executores auto-hospedados](self-hosted-runners/remove-runners.md)

  Você pode remover permanentemente um executor auto-hospedado de um repositório ou organização.
