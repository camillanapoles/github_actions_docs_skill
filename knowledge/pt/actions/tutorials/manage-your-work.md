# Gerenciando seu trabalho com o GitHub Actions

_Você pode gerenciar automaticamente seus problemas e pull requests usando fluxos de trabalho de GitHub Actions._

## Links

* [Adicionando etiquetas a problemas](manage-your-work/add-labels-to-issues.md)

  Você pode usar GitHub Actions para rotular problemas automaticamente.

* [Fechar questões inativas](manage-your-work/close-inactive-issues.md)

  Você pode usar o GitHub Actions para comentar ou fechar problemas inativos por um determinado período de tempo.

* [Comentar sobre um problema quando uma etiqueta é adicionada](manage-your-work/add-comments-with-labels.md)

  Você pode usar GitHub Actions para comentar automaticamente sobre problemas quando um rótulo específico é aplicado.

* [Agendar a criação de problemas](manage-your-work/schedule-issue-creation.md)

  Você pode usar o GitHub Actions para criar um problema regularmente para itens como reuniões diárias ou revisões trimestrais.
